# Anime Recommendation System

## Project Overview

This project implements three types of recommendation systems for anime:

1. Content-Based Filtering
2. Collaborative Filtering (KNN)
3. Hybrid Recommendation System

The system recommends anime based on genre similarity and user rating patterns.

## Dataset

Dataset files:

* anime.csv
* rating.csv

The dataset contains anime information, genres, ratings, and user interactions.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Jupyter Notebook

## Content-Based Filtering

Uses:

* Genre information
* CountVectorizer
* Cosine Similarity

The system recommends anime with similar content and genres.

## Collaborative Filtering

Uses:

* User-Anime Rating Matrix
* Pivot Table
* Sparse Matrix
* K-Nearest Neighbors (KNN)

The system recommends anime based on similar user preferences.

## Hybrid Recommendation System

Combines:

* Content-Based Recommendations
* Collaborative Filtering Recommendations

to generate improved recommendations.
